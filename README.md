# Airbnb Market & Tourism Analysis

An academic data-analysis and machine-learning project exploring Airbnb listing data, market patterns, and factors associated with listing prices.

## Project focus

- Exploratory data analysis of listing characteristics and price distributions
- Data cleaning, missing-value handling, and feature engineering
- Analysis of price-related features, including price per bed
- Dimensionality reduction and clustering to explore listing segments
- Regression-model comparison for price prediction

## Modelling work

The project work explored a range of regression approaches, including linear models, decision trees, ensemble methods, gradient boosting, CatBoost, K-nearest neighbours, and support vector regression.

Previously discussed experiments identified CatBoost Regressor as the strongest of the compared models in that analysis. Exact scores are intentionally not published here until the source notebook and evaluation outputs are added and rechecked.

## Technology areas

Python · Pandas · NumPy · Matplotlib · Seaborn · Scikit-learn · XGBoost · CatBoost

## Current publication status

This repository currently contains the project overview only. The analysis notebooks, dataset source, preprocessing steps, and reproducible evaluation results have not yet been published here. No dataset is included.
